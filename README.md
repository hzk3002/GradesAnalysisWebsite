# 成绩分析工作台

一个**单文件、纯本地、不上传**的中学成绩分析网页。下载一个 HTML 双击打开就能用，不需要安装、不需要联网、不需要账号。

- 🌐 **在线直接用**：<https://hzk3002.github.io/GradesAnalysisWebsite/>
- 💾 **离线版**：下载本仓库的 [`index.html`](index.html)，双击用 Edge / Chrome 打开即可

数据全部留在你自己的浏览器里（localStorage），页面不会把任何学生成绩发到服务器。

---

## 一、打开方式（任选一种）

| 方式 | 操作 | 适用 |
|---|---|---|
| 在线版 | 点上面的链接 | 日常使用、换电脑也能开（数据需自行迁移） |
| 离线版 | 下载 `index.html` → 双击 | 无网环境、数据只放本机 |

> ⚠️ **在线版和离线版的数据是两套，互不相通。**
> 浏览器里的本地存储按「来源」隔离，`https://hzk3002.github.io/...` 与 `file:///.../index.html` 是两个不同的来源。
> 换环境时请用页面顶部的**「导出 / 导入备份」**搬运数据（导出一个 JSON 文件）。

## 二、四个页面

| 页面 | 主要用途 |
|---|---|
| **总成绩分析** | 导入总分成绩单（Excel），看班级/年级排名、进退步、分数段、科目热力表、三栏趋势图 |
| **数学成绩分析** | 导入数学小题得分表，看知识点/题型得分率、逐题诊断，生成数学报告单 |
| **后台 · 建议维护** | 维护分档标准、学科达标线、阶段建议等模板文案，导出/导入题目配置 |
| **高考成绩分析** | 按校内位次与两校联排位次，给出参考分位与高考分数区间定位；含全市一分一段分布 |

---

## 三、导入数据的要求

1. **格式**：Excel `.xlsx / .xls`（第一行是表头）。
2. **必需列**：`姓名`、`班级`，以及 `总分` 和各科成绩列（语文、数学、英语、选科……）。
3. **强烈建议有 `学校` 列**：用来区分「汇文中学 / 汇文实验」。没有这一列时，程序会退化成按班号判断，班号一变就会算错校排。
4. **无效成绩的写法**：单元格里写 `不计入`、`缺考`、`-` 等非数字内容的，按「无效」处理，不参与排名。
5. **小题得分列是文本也没关系**（如 `"5"`、`"3.5"`），程序会转成数字；整列都是 `-` 的科目会被标记为「本次无数据」，并在页面顶部提示。
6. 导入后数据自动留在本浏览器，下次打开还在。

## 四、排名口径（最容易出错的地方）

| 名词 | 含义 |
|---|---|
| **校排**（校区排名） | 只在本校区（如汇文实验）内部排名 |
| **联排**（联合排名） | 两校所有学生合并后统一排名 |

- **班级 → 学校归属**在「高考成绩分析」页可改，默认 `11、12、13、14、15` 班属于**汇文实验**，其余属于**汇文中学**（该页有「恢复默认 11–15 班」按钮）。
  班号跨学期会变，**换考试请先核对这一项**。
- 如果成绩单里自带「校排 / 联排」列，程序会先做一致性校验（是否随总分单调、是否超出参考人数），通过就用原列；不通过才按总分自算，并在页面上说明。

---

## 五、高考预测怎么读（重要）

页面上给出的 **`AI预测X分`** 是**区间定位示意**，不是高考成绩预测：

- 它把「本次校内位次」近似成「高考时的校内位次」，再在设定的分数区间内按全市一分一段的累计分布反查；
- 不计入考试难度差异、个人进步趋势、选科差异、位次波动；
- 同一分位下不同学校给出不同分数，是因为两校的高考分数区间不同（汇文中学 521~687、汇文实验 420~630，均可在页面上改）。

**正确用法**：看「参考分位约 P%」和「大致落在哪个分数区间」，用来定位学生当前所处的位置；不要把它当作高考成绩的承诺。

## 六、报告单与打印

- **总成绩报告单**：A4 纸 40 页，每页带页脚；各科成绩分左右两栏（左：总分与语数英，右：选考科目）。
- **数学报告单**：点「预览 / 打印报告单」生成，含逐题诊断与学习建议。
- 打印设置：`Ctrl + P` → 纸张 **A4** → 边距 **默认** → **勾选「背景图形」**（否则优秀/未达线的底色会丢失）。
- 建议用 Chrome / Edge 打印或以「另存为 PDF」输出。

## 七、常见问题

| 现象 | 原因与处理 |
|---|---|
| 校排数字明显不对 | 旧备份里没有 `学校` 字段。请**重新导入原始成绩单**（含「学校」列），或手动核对该考试的班级归属 |
| 某科目整列空白 | 数据源该列没录入（常见于某校区漏统语文）。页面顶部会提示「无数据」，不是程序漏读 |
| 打印出来两栏变成上下堆叠 | 打印设置里把缩放调为 100%，或改用「另存为 PDF」 |
| 图表/底色打印不出来 | 打印时勾选「背景图形」 |
| 换电脑后数据不见了 | 本地存储不跟随账号。请用「导出备份 / 导入备份」迁移 |
| 浏览器清缓存后数据没了 | 同上。建议每次录入后导出一次备份 |
