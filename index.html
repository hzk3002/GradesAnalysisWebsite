③ 题目设置（满分 / 类型 / 知识点 / 难度） 用于知识板块诊断与学习建议
默认按北京卷结构预填且均可修改：1-10 题每题 4 分、11-15 题每题 5 分、16 三角 13 分、17 立体 14 分、18 统计 14 分、19 解析几何 14 分、20 函数 15 分、21 新定义 15 分。类型从下拉选（共 11 项：集合、函数、三角、数列、向量、复数、立体、解析几何、计数原理、统计、新定义），类型相同的题目自动合并统计得分率并给复习意见；知识点为备注信息，不参与合并。1-15 题未选类型时统一归入「未分类题目」。
知识点填写后会显示在报告单每道题旁。各板块得分率达标线（良好 / 优秀）可在下方「知识板块达标线」里逐类调整；默认新定义 25/50，其余 55~92（%）。选填 / 解答两段在「题型专项达标线」中单独设定，用于判定该生所属档位并给出对应复习策略。报告单按这两套达标线判定水平、生成板块与题型两栏建议。
知识板块达标线（11 类可分别设置） 得分率 ≥ 良好线判「良好」，≥ 优秀线判「优秀」
不同板块难度不同，可按自己的判断调整：报告单的「掌握」标签、分析页的学习意见均按此判定。默认 新定义 良好25% / 优秀50%，其余按板块 55%~92% 递增。
题型专项达标线（选填 / 解答） 决定报告单「题型专项」建议的档位
选填题 = 选择题 T1–10 + 填空题 T11–15；解答题 = T16 及以后。两段得分率各有不同的复习策略，此处的良好 / 优秀线用于判定该生属于哪一档。
题目配置导入 / 导出 题型、知识点、难度、满分可搬到别的电脑或别的考试
导出的 JSON 记录每道题的题号、满分、类型、知识点、难度，并附带 11 类板块与选填 / 解答的达标线；导入时按题号自动匹配，文件里的空白项不会覆盖你已填的内容。CSV 版可在 Excel 中查看与留档。

⑤ 导出报告单（每人一页纸） 按题目类型合并得分率 + 学习建议
按班级生成数学报告单，打印 / 存为 PDF。汇总表按题目类型（知识板块）合并，未选类型的题目归入一行「未分类题目」，每人一页 A4。建议内容随学习阶段（一轮 / 二轮 / 冲刺）切换口径。
学习建议库维护
这里是报告单与分析页「学习建议」的唯一文案来源：改写任意一条并保存，分析页表格与报告单（板块针对性提升 / 题型专项 / 本轮重点）会立刻改用新文案。清空某条并保存 = 该条恢复默认。
写多长有讲究：报告单每页最多列 3 条板块建议，单条建议控制在 110 字以内较稳妥；超过 110 字会标红提示，超过 160 字将不允许保存（会把一页 A4 撑成两页）。
改完记得保存；保存后分析页与报告单立即使用新文案。
